# Appointment No-Show Analysis

## Tujuan
Menganalisis pola kehadiran pasien pada dataset Appointment No-Show untuk berlatih eksplorasi dan analisis data menggunakan Python dan Pandas.

## Pertanyaan Analisis Awal
- Berapa proporsi janji temu yang berakhir dengan no-show?
- Bagaimana distribusi no-show berdasarkan kelompok usia?
- Apakah terdapat perbedaan pola berdasarkan hari atau faktor lain yang tersedia pada dataset?
- Apa keterbatasan data dan interpretasi yang perlu diperhatikan?

## Rencana Pengerjaan
1. Memastikan sumber dan lisensi dataset.
2. Memahami kolom, tipe data, dan ukuran dataset.
3. Memeriksa data kosong, duplikat, dan konsistensi nilai.
4. Melakukan eksplorasi dan visualisasi.
5. Menuliskan temuan, keterbatasan, dan kesimpulan.

## Tools
- Python
- Pandas
- Matplotlib
- Google Colab atau Jupyter Notebook

## Struktur
- `data/` — petunjuk penyimpanan dataset lokal; file dataset tidak otomatis diunggah.
- `notebooks/` — notebook analisis.
- `reports/figures/` — grafik hasil analisis.

## Catatan
Proyek ini untuk pembelajaran analisis data, bukan untuk menilai atau menentukan keputusan klinis. Jangan unggah data pasien yang dapat mengidentifikasi seseorang.
