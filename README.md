# Medical Informatics Portfolio

Portofolio pembelajaran dan proyek **S1 Informatika Medis**. Repository ini mendokumentasikan proses belajar, latihan, dan proyek yang menggabungkan teknologi informasi dengan bidang kesehatan.

## Tentang Portofolio

Saya merupakan mahasiswa S1 Informatika Medis yang sedang mengembangkan keterampilan teknis dan pemahaman sistem informasi kesehatan sebagai bekal akademik, magang, dan karier.

Fokus pembelajaran:
- **Database & SQL** — perancangan tabel, relasi, query, dan pengelolaan data.
- **Data Analysis** — Python, Pandas, visualisasi, dan interpretasi data kesehatan.
- **Machine Learning** — dasar supervised learning dan evaluasi model.
- **Health Information Systems** — konsep rekam medis elektronik dan pengembangan sistem sederhana.

## Daftar Proyek

| Bidang | Proyek | Status |
|---|---|---|
| Data Analysis | Appointment No-Show Analysis | Persiapan |
| Database & SQL | Latihan dan perancangan database | Direncanakan |
| Machine Learning | Healthcare Classification | Direncanakan |
| Health Information Systems | Patient Management System sederhana | Direncanakan |

Status akan diperbarui seiring perkembangan proyek. Proyek yang belum selesai tidak akan ditampilkan sebagai proyek final.

## Prinsip Pengelolaan Data

- Menggunakan dataset publik, data sintetis, atau data yang telah dianonimkan dan memang boleh digunakan.
- Tidak mengunggah identitas, rekam medis, atau informasi pribadi pasien.
- Menjelaskan sumber data, tahapan analisis, keterbatasan, dan tujuan setiap proyek.
- Hasil machine learning dalam repository ini ditujukan untuk pembelajaran, bukan untuk diagnosis atau keputusan klinis.
